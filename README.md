I work across Rust, TypeScript, Python, and web technologies, with an emphasis on local control and clear human decisions.

## Selected projects

The first projects combine sustained development, recent work, and public interest. Each links to the source and technical documentation.

1. **[Claude Skills](https://github.com/glebis/claude-skills)** — A collection of roughly 100 reusable Claude Code skills covering research, development, releases, media, and personal workflows. Packaged for installation as plugins or individual skills.
2. **[Cull](https://github.com/glebis/cull)** — A local-first macOS image review and curation app built with Rust, Tauri, Svelte, and SQLite. It combines fast visual workflows with local embeddings, provenance-aware metadata, and CLI/MCP access for agents. [Product site](https://cull.company/)
3. **[Humane Agentic Design](https://github.com/glebis/humane-agentic-design)** — A set of 21 design-method skills that take agent-assisted work from problem framing through prototyping and review, with explicit evidence and human judgment. [Method guides](https://humane.salient.community/)
4. **[Genome Toolkit](https://github.com/glebis/genome-toolkit)** — A Python and Obsidian toolkit for importing consumer genome data, organizing evidence, and exploring variants and pharmacogenomics. Its outputs distinguish evidence tiers and limits rather than presenting uncalibrated genetic findings as clinical predictions.
5. **[PiBot](https://github.com/glebis/pibot)** — A TypeScript runtime for personal agents built on the pi SDK. It includes Telegram and CLI transports, per-agent memory and plugins, scheduling, capability controls, and explicit approval for sensitive actions.
6. **[cenno](https://github.com/glebis/cenno)** — A macOS question-and-answer runtime for MCP agents. Floating panels collect structured answers without taking keyboard focus; exchanges are stored locally. Built with Rust and Tauri.

## More technical work

- **[Verity](https://github.com/glebis/verity-agent)** — A Telegram agent built with the Claude Agent SDK, combining research, Obsidian knowledge workflows, voice and media, scheduling, and per-user data controls.
- **[CONFIDE](https://github.com/glebis/confide)** — A local-first, bilingual transcript de-identification toolkit and synthetic benchmark with re-identification tests for sensitive therapy and coaching data.
- **[Claude Relay MCP Server](https://github.com/glebis/claude-relay-mcp-server)** — An MCP server for routing work and messages between Claude Code sessions, with persistent storage and access controls.
- **[Polar H10 Ribbon](https://github.com/glebis/polar-h10-ribbon)** — A real-time biofeedback experiment connecting Polar H10 heart-rate data to ambient lighting, generative music, and breathing guidance.
- **[Generative Sequencer](https://github.com/glebis/generative-sequencer)** — A browser-based music sequencer with Web Audio synthesis, radial visualization, and AI-assisted layer creation.
