# Gleb Kalinin

I build tools for creative work, knowledge, and personal data, often with agents in the workflow. My public work spans image curation, personal agents, design methods, and privacy-sensitive workflows, with an emphasis on local control and clear human decisions.

Based in Berlin. [Website](https://glebkalinin.com/) · [LinkedIn](https://www.linkedin.com/in/glebkalinin/)

## Selected projects

The first projects combine sustained development, recent work, and public interest. Each links to its repository for a closer look.

1. **[Claude Skills](https://github.com/glebis/claude-skills)** — A collection of roughly 100 reusable Claude Code skills covering research, development, releases, media, and personal workflows. Packaged for installation as plugins or individual skills.
2. **[Cull](https://github.com/glebis/cull)** — A local-first image review and curation app for working through large collections without changing the originals. It supports visual similarity search, keeps generation history with images, and lets agents work with the library directly. [Product site](https://cull.company/)
3. **[Humane Agentic Design](https://github.com/glebis/humane-agentic-design)** — A set of 21 design-method skills that take agent-assisted work from problem framing through prototyping and review, with explicit evidence and human judgment. [Method guides](https://humane.salient.community/)
4. **[Genome Toolkit](https://github.com/glebis/genome-toolkit)** — A toolkit for importing consumer genome data, organizing evidence, and exploring variants and pharmacogenomics. Its outputs distinguish evidence tiers and limits rather than presenting uncalibrated genetic findings as clinical predictions.
5. **[PiBot](https://github.com/glebis/pibot)** — A runtime for personal agents with chat, memory, scheduling, and per-agent capabilities. Sensitive actions require explicit approval, and each agent can have its own tools and long-term context.
6. **[cenno](https://github.com/glebis/cenno)** — A macOS app that lets agents ask questions through small floating panels and receive structured answers. It preserves keyboard focus and stores exchanges locally.

## More projects

- **[Verity](https://github.com/glebis/verity-agent)** — A personal Telegram agent combining research, knowledge workflows, voice and media, scheduling, and per-user data controls.
- **[CONFIDE](https://github.com/glebis/confide)** — A local-first, bilingual transcript de-identification toolkit and synthetic benchmark with re-identification tests for sensitive therapy and coaching data.
- **[pi-extensions](https://github.com/glebis/pi-extensions)** — Extensions that connect a coding agent to answer panels, Telegram, project servers, and multi-agent workspaces, with clear boundaries around consent and cleanup.
- **[Claude Relay MCP Server](https://github.com/glebis/claude-relay-mcp-server)** — A way to route work and messages between agent sessions, with persistent storage and access controls.
- **[Polar H10 Ribbon](https://github.com/glebis/polar-h10-ribbon)** — A real-time biofeedback experiment connecting Polar H10 heart-rate data to ambient lighting, generative music, and breathing guidance.
- **[Generative Sequencer](https://github.com/glebis/generative-sequencer)** — A browser-based music sequencer with a radial interface and AI-assisted layer creation.
- **[Obsidian 4D Graph Explorer](https://github.com/glebis/obsidian-4d-graph-explorer)** — An interactive view of notes and links as a four-dimensional graph, with cluster insights and controls for exploring connections.
